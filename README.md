# Advertising Campaign Excel Dashboard

An interactive Excel dashboard designed to analyse advertising campaign performance, advertising spend, campaign activity, and airtime delivery.

## Project Overview

This project focuses on analysing advertising campaign data and transforming it into an interactive Excel dashboard.

The dashboard provides a consolidated view of campaign activity across brands, radio stations, provinces, campaign statuses, advertising spend, and booked versus aired advertising spots.

The purpose of the project is to turn raw campaign data into meaningful business information that can support reporting, monitoring, and decision-making.

---

## Business Problem

Advertising campaign data can contain a large number of records across different brands, stations, provinces, campaigns, and advertising spots.

Without a centralised reporting dashboard, it can be difficult to quickly determine:

- Which brands have the highest advertising spend
- Which stations aired the most advertisements
- Which provinces have the highest campaign activity
- How many advertising spots were booked versus aired
- How campaigns are distributed by status
- How advertising spend differs between brands

This project addresses these challenges by consolidating the information into an easy-to-use Excel dashboard.

---

## Project Objectives

The objectives of this project were to:

1. Clean and prepare the advertising campaign data.
2. Analyse advertising spend by brand.
3. Analyse campaign activity by province.
4. Identify stations with the highest advertising activity.
5. Compare booked versus aired advertising spots.
6. Analyse campaign performance.
7. Analyse campaign status distribution.
8. Calculate and compare average advertising spend by brand.
9. Present the findings through an interactive Excel dashboard.

## Dashboard Analysis

The dashboard contains several analytical views.

### Brand Spend

Analyses advertising expenditure across different brands.

### Province with Most Campaigns

Identifies provinces with the highest number of advertising campaigns.

### Stations Aired the Most Adverts

Highlights radio stations with the highest advertising activity.

### Average Spend by Brand

Compares the average advertising spend across brands.

### Booked vs Aired Spots

Compares advertising spots that were booked against spots that were actually aired.

### Campaign Performance

Provides an overview of campaign performance.

### Campaign Status Distribution

Shows the distribution of campaigns according to their status.
